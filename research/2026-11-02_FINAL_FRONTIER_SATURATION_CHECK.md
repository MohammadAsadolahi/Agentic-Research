## Additional important niche frontiers (positive records)

1. [Agentic Hardware Design as Repository-Level Code Evolution / HORIZON](https://arxiv.org/abs/2606.28279), June 26 2026. Public original abstract demonstrates agent-controlled hardware-description/design artifact evolution over ChipBench, RTLLM, Verilog-Eval and nine CVDP categories. The author's benchmark-success claim is not external proof of physically valid chip designs. **Classify as** autonomous engineering and formal/executable artifacts inside Software Engineering/Autonomous R&D.
2. [MathCoPilot](https://arxiv.org/abs/2607.14582), July 16. Human-AI jointly directed mathematical discovery with Lean proof search and a living proof blueprint. **Classify as** AI for Science + Human-Agent Co-agency.
3. [Growing an Agent/Prover Interface](https://arxiv.org/abs/2609.39544), Sept 30. Evolves Rocq/Lean proof-assistant tool API and tests held-out theorem proving. **Direct novelty threat** to generic agent-native formal-method interface generation. **Classify as** tool ecosystem adaptation + autonomous R&D.
4. [Lean Finder V2](https://arxiv.org/abs/2610.30843), Oct 22. Disambiguates short implicit mathlib queries and improves proof-agent retrieval. **Classify as** agent-specific tools/retrieval within established mathematical formalization.
5. [TLA-Verus](https://arxiv.org/abs/2610.14923), Oct 10. Agentically generates machine-checkable temporal safety/liveness proofs from TLA+ specs. **Classify as** formally verified software engineering with agent-generated artifacts.
6. [Inductive Deductive Synthesis](https://arxiv.org/abs/2605.23109), May 22. Implementation and proof co-synthesis in distributed systems; **direct strong prior method**, not generic new agent verification opportunity.

## Honest completeness judgment

The **major-family coverage** is defensible after cross-domain exploratory search, but **all emerging subfields** cannot be certified by any finite keyword-based search. There may be numerous new specializations in niche conferences and different languages. The 111-item master index is a **working ontology**, not a bibliometric census or an objectively correct segmentation of AI.

**Stop condition for more generic scouting:** Recent searches mainly add specialties inside mapped families; repeat scans are yielding diminishing *conceptual* novelty. Next work should identify a specific measurable failure and execute real baseline agent runs. A truly new macrofamily can be added when supported by evidence.

**One extra warning:** mathematical theorem proving/hardware autonomy have powerful earlier symbolic systems and verification methods; their high technical difficulty is not an easy novelty shortcut. The field-first atlas deliberately does not rank these as default small-team targets.
